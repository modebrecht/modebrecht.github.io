BO2026 · Notfallmodus

Vercel tot?
Daten trotzdem retten.

BO2026 speichert den Arbeitsstand im Browserprofil. Diese Seite hilft dir, die Daten von bo2026.vercel.app direkt aus Chrome, Edge, Firefox oder Safari zu retten – ohne dass Vercel erreichbar sein muss.

!

Erste Regel: Browser komplett beenden.

Nicht im Live-Profil herumprobieren. Erst Browser schließen, dann Daten auslesen. Das Recovery-Skript liest nur; es verändert keine Browserdaten.

1

Browser schließen

Chrome / Edge / Firefox / Safari wirklich beenden, damit Datenbanken konsistent und nicht gesperrt sind.

2

Script starten

Das Script sucht automatisch bekannte Profile und nur nach BO2026-relevanten LocalStorage-Daten.

3

JSON sichern

Gefundene Stände landen als einzelne JSON-Dateien plus Manifest auf dem Desktop.

Universal BO2026 Recovery Script

Windows + macOS · Chrome · Edge · Firefox · Safari

Recommended

Einmalige Vorbereitung

py -m pip install "git+https://github.com/cclgroupltd/ccl_chromium_reader.git" python-snappy

Die Zusatzmodule werden für Chromium-LevelDB und komprimierte Firefox-Werte benötigt. Ist nur Vercel ausgefallen, kann die Installation weiterhin über GitHub/PyPI erfolgen.

Start

py bo2026_recover.py

Ergebnis: Desktop/BO2026-Recovery-YYYYMMDD-HHMMSS/. Das Script scannt alle üblichen Profile und erstellt pro Fund eine JSON-Datei.

Wo liegen die Daten?

Chrome

Windows

%LOCALAPPDATA%\Google\Chrome\User Data\Default\Local Storage\leveldb

Weitere Profile liegen unter Profile 1, Profile 2 usw.

macOS

~/Library/Application Support/Google/Chrome/Default/Local Storage/leveldb
Microsoft Edge

Windows

%LOCALAPPDATA%\Microsoft\Edge\User Data\Default\Local Storage\leveldb

macOS

~/Library/Application Support/Microsoft Edge/Default/Local Storage/leveldb
Firefox

Windows

%APPDATA%\Mozilla\Firefox\Profiles\<profil>\storage\default\https+++bo2026.vercel.app\ls\data.sqlite

macOS

~/Library/Application Support/Firefox/Profiles/<profil>/storage/default/https+++bo2026.vercel.app/ls/data.sqlite

Firefox kann Werte in data.sqlite mit Snappy komprimieren. Das Recovery-Skript berücksichtigt das.

Safari

macOS · aktuelles Safari

~/Library/Containers/com.apple.Safari/Data/Library/WebKit/WebsiteData/

Falls macOS den Zugriff verweigert: Terminal unter Systemeinstellungen → Datenschutz & Sicherheit → Festplattenvollzugriff erlauben. Moderne Safari-Versionen nutzen WebKit-WebsiteData und können mehrere Profile besitzen.

Windows · nur altes Safari

%APPDATA%\Apple Computer\Safari\LocalStorage
%APPDATA%\Apple\Safari\LocalStorage

Legacy-Fall: Apple bietet Safari für Windows nicht mehr an. Das Script scannt diese alten Speicherorte trotzdem.
