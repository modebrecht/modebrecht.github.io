BO2026 · Notfallmodus

Vercel tot?
Dossier trotzdem retten.

Der BO2026-Arbeitsstand liegt im Browserprofil. Dieses Kit liest bo2026.vercel.app lokal aus und erzeugt neben einem Rohbackup jetzt auch direkt eine BO2026-importierbare Dossier-JSON.

!

Desktop schließen. Android-Tab offen lassen.

Desktop: Browser vor dem Profil-Scan vollständig beenden. Chrome Android: Wenn der BO2026-Tab noch offen ist, Chrome NICHT schließen – dieser Tab ist ohne Root deine beste Rettungsmöglichkeit.

1

Desktop-Browser schließen

Chrome, Edge, Brave, Vivaldi, Opera, Firefox oder Safari am PC/Mac vollständig beenden. Auf Android einen noch offenen BO2026-Tab dagegen offen lassen.

2

Recovery starten

Das Skript durchsucht die üblichen Profile nach dem BO2026-Origin.

3

Projekt laden

Bewerbungsdossier-RECOVERED-*.json danach in BO2026 über „Projekt laden“ öffnen.

Universal BO2026 Recovery

Chrome · Edge · Brave · Vivaldi · Opera / Opera GX · Firefox · Safari (Best Effort)

Recommended

Windows One-Click: Der Build-Workflow erzeugt eine eigenständige BO2026-Recovery-Windows.exe ohne Python/pip/Git auf dem Ziel-PC. Sobald der erste Build fertig ist, wird hier ein direkter EXE-Download ergänzt.

Einmalige Vorbereitung

py -m pip install "git+https://github.com/cclgroupltd/ccl_chromium_reader.git" python-snappy

Start

py bo2026_recover.py

Ausgabe auf dem Desktop: Rohbackup *-RAW.json + direkt importierbares Bewerbungsdossier-RECOVERED-*.json + manifest.json.

Safari · Best Effort

Best Effort: Safari/WebKit-Speicherorte können je nach macOS-, Safari- und Profilversion variieren. Das Skript prüft mehrere bekannte Speicherorte, eine Rettung kann aber weniger zuverlässig sein als bei Chromium/Firefox.

macOS · aktuell

~/Library/Containers/com.apple.Safari/Data/Library/WebKit/WebsiteData/

Falls macOS blockiert: Terminal unter Datenschutz & Sicherheit → Festplattenvollzugriff freigeben.

Windows · Legacy Safari

%APPDATA%\Apple Computer\Safari\LocalStorage

Nur Altbestand: Safari für Windows wird seit Jahren nicht mehr weiterentwickelt.

Chrome Android

Ohne Root · BO-Tab lebt noch

Beste Chance ohne Root: Android per USB an einen PC/Mac anschließen, USB-Debugging aktivieren und den noch geöffneten BO2026-Tab über Desktop-Chrome remote inspizieren.

Desktop Chrome

chrome://inspect/#devices

Beim BO2026-Tab auf Inspect → Application → Local Storage → https://bo2026.vercel.app. Alternativ in der Console den LocalStorage exportieren. Funktioniert nur, wenn ein passender Tab/Context noch existiert.

Ohne Root · kein BO-Tab mehr

Kein verlässlicher Direktzugriff. Android schützt Chromes internes App-Verzeichnis. Ein normaler Dateimanager, eine andere App oder ein gewöhnlicher ADB-Zugriff kann den Chrome-LocalStorage nicht einfach lesen. Auf Android 12+ ist auch adb backup für solche App-Daten keine allgemeine Rettungslösung.

Wichtig: Chrome nicht deinstallieren und „App-Daten löschen“ nicht drücken – dabei können die lokalen Daten verschwinden.

Mit Root · echte Profilrettung

Chrome App-Daten

/data/user/0/com.android.chrome/app_chrome/Default/Local Storage/leveldb

Beispiel via ADB + su

adb shell su -c 'tar -czf /sdcard/Download/bo2026-chrome-leveldb.tgz -C /data/user/0/com.android.chrome/app_chrome/Default "Local Storage/leveldb"'
adb pull /sdcard/Download/bo2026-chrome-leveldb.tgz

Danach Archiv am PC entpacken und den enthaltenen leveldb-Ordner mit demselben Chromium-Reader auswerten.

Was wird gerettet?

Origin https://bo2026.vercel.app. Bekannte Schlüssel: titelblatt:v3, anschreiben:v1, lebenslauf:v1, bewerbungsdossier:chrome:v1 plus Layout-, Placement- und Foto-Sidecars.

Das importierbare Recovery-JSON entspricht dem BO2026/CV-Cover-Charm-Projektformat cv-cover-charm-dossier Version 1.
